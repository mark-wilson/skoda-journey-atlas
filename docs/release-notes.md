# v1.0.0-beta.1 — first public beta

Škoda Journey Atlas is an independent companion to MyŠkoda for exploring exported journey statistics on a map, refining road routes, adding notes and stops, and keeping a portable backup of your atlas.

## Included

- Import MyŠkoda journey-statistics CSV files with duplicate and revision review.
- Explore journeys on an interactive map and inspect individual journey details.
- Refine estimated road routes using shaping points, intermediate stops, charging stops and turnarounds.
- Correct journey details, record notes and identify journeys needing review.
- Create and restore JSON data backups, and delete locally stored data.
- Illustrated user guide, demonstration screenshots and MIT licence.

## Beta scope

Developed and tested with a 2026 Škoda Enyaq running vehicle software 6.0.1 and the MyŠkoda for iOS 8.18.0 App Store release. Other vehicle and app combinations may produce different exports. Road routes are estimates, not recorded GPS tracks.

Journey data is stored in the browser. Create a JSON backup before clearing browser storage or switching browsers. Map tiles and routing use external services.

Feedback and issues are welcome. Please redact any personal location or journey information before posting publicly.

## Getting started

Download the repository ZIP, extract it, and open `index.html` in your browser. No web server or developer tools are required. See `docs/user-guide.md` for instructions.

This release is marked **Pre-release** on GitHub. The first stable release will be `v1.0.0` after beta feedback.
